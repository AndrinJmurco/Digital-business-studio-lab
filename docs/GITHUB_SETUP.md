# Setup and maintenance

Clone the GitHub repository to your computer. Keep private records, personal profiles, customer lists, secrets and contracts outside this public source repository.

Run:
```sh
python3 scripts/validate_repo.py
python3 scripts/extract_dashboard_js.py | node --check
```

Start from [the project plan](PROJECT_PLAN.md) and [backlog](BACKLOG.md). Create an optional GitHub Project with stages Backlog / Research / In Progress / Validation / Done. The ChatGPT plugin remains a separate private installation.
