# Ghostwriter-style agent workbench (54 ORIGINAL recipes)
This is not Monetise's GhostWriter OS or its undisclosed prompts. Their public site says 50+ specialist agents; our independent 54-agent catalog is at `../../assets/AGENT_LIBRARY.md`.

## Routing
1. Identify customer, offer, proof, audience stage, channel, desired action and tone from current project. Reuse existing data; do not ask repeatedly. If no data, state assumptions and produce draft.
2. Find relevant ID G01–G54 in library. Treat each role as a fixed deliverable contract, not autonomous access to a social account.
3. Generate the requested material using the recipe's inputs and output, with one clear CTA and platform-appropriate length. For buyer-facing material use buyer's language. Produce multiple angles only if helpful.
4. QC: no fabricated sales, scarcity, earnings, social proof, testimonials, case studies, or affiliation; mark anecdote placeholders clearly. Ensure accessible copy, safe claims and actionable next step; cite source for factual market claims.
5. Attach a short performance hypothesis and trackable metric. Don't declare a message winning until real data exists. Never send, post, buy ads or touch an outside system without explicit user approval.

## Useful commands
'Run G21 for this offer'; 'Produce a creator gameplan and one DM'; 'Generate an original 14-day launch content package'; 'Rewrite the sales page using customer objections'.
