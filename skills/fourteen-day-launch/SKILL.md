# Original 14-day launch sequencer
Uses public framework idea, not Monetise's private GhostWriter output; no access to creator social accounts. Inputs: permission status, product, audience, primary channel, launch window, one CTA, links only if real, exclusions, expected workload, refund rules and owner. Default 1 content unit per day **draft**; user or creator decides whether to publish. Without audience permission, treat as a sample calendar rather than sending to followers.

Days 1–2: validate pain with helpful questions and no false promises.
Days 3–4: share useful education and existing alternatives.
Days 5–6: tease the proposed solution and request voluntary feedback.
Days 7–8: show real MVP function, demo/worksheet and how it solves a task.
Day 9: publish transparent offer (if lawful/approved) or opt-in interest page.
Day 10: answer FAQs/fit and limitations, avoid fake testimonials.
Day 11: show practical use case, mark illustrative example as sample.
Day 12: invite genuine questions, respond to actual replies.
Day 13: straightforward reminder with factual availability only.
Day 14: summarize learnings and invite feedback; no invented deadline.

For each day output channel, specific hook, body/frames, honest CTA, visual requirement, owner, evidence/status, estimated minutes, performance measure. Cap operator tasks at confirmed weekly capacity per week; batch production where possible and flag creator contribution. Include launch gate: signed rights, verified payment/delivery rules, test of product quality, user authorization. No live publishing or automatic messaging. Include post-launch pivot thresholds based on pre-committed qualified visits, price and paid orders.
