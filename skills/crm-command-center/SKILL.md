# Flozy-style lightweight CRM (original offline tool)
Bundled files: `../../assets/business-studio-offline.html`, `../../assets/creator-pipeline.csv`, `../../assets/PROJECT_STATE_TEMPLATE.md`. This is **not Flozy**. The HTML is a standalone browser tool with local-only storage, JSON backup and simple calculations; it has no live account sync, scraping, email sending, payment processing, or ChatGPT tool connection. Recommend exporting a backup because local/browser storage can be cleared.

Pipeline stages: Research → Qualified → Draft ready → Permission requested (after approval only) → Interested → Discovery → Scope agreed → Pilot → Live → Won/Closed/Lost. Use actual dates and reliable links; don't invent real prospects or status. No collection of private emails without consent; prefer public professional contact methods. Keep opt-out and nonresponse handling. Track creators as potential *partners* and buyers/orders separately; do not add fake purchases.

Metrics: number genuinely qualified, personalized proposals approved/sent, responses, meetings, signed rights, pilot starts, first purchases, attributable net receipts, working hours and cash. Only calculate rates when denominator and time period are known. For connected Google Sheets/Airtable, check user permission and use available connectors, preserving table identity; don't create data silently.

If user asks to show funnel, use actual provided data; otherwise create an empty or labeled demo pipeline. Use a single dated next action per prospect and a weekly 15-minute review.
