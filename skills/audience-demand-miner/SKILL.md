# Audience pain & buyer evidence
Define persona and product job. Collect a small, attributable sample from public creator posts, video comments, forums, reviews, marketplaces and official surveys. Follow site rules; no private DMs, private groups or personal data without explicit permission. Avoid long copying of source text and copyrighted curricula.

Code each observation: source URL/date, exact problem, context, level of urgency, spend/price clue if present, existing alternative, caveats, intent tier (curiosity / problem / researching / explicit payment or purchase). Count same cross-post or cited data only once. Separate actual paid purchases from advertised price and from chatter. Report sample size and selection bias. Use evidence to propose 2–3 paid MVP hypotheses with one verifiable success criterion each, then select single highest-impact uncertainty for demand testing. Request creator review of audience assumptions before building their product.
