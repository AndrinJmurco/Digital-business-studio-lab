# Digital Business Studio Lab

An **independent public starter kit** for discovering, validating, prototyping and launching original digital products and permission-based educational creator collaborations.

**Not affiliated with Monetise, Synthesise AI, GhostWriter OS, Flozy, or Whop.** No proprietary code, paid training, internal prompts or privileged services are provided.

## Included files
- [26 reusable skills](skills/) for business discovery, product design, creator collaborations, marketing and evaluation.
- [54 original agent recipes](assets/AGENT_LIBRARY.md). These are prompt/workflow recipes, **not** independently hosted agents.
- [Offline business dashboard](assets/business-studio-offline.html), which runs in a browser and stores local data, not in a connected CRM.
- [Planning documents](docs/PROJECT_PLAN.md), [backlog](docs/BACKLOG.md), [evidence ledger](docs/EVIDENCE_LOG.md), GitHub issue templates, and validation scripts.

## Quick start
1. Read [the plan](docs/PROJECT_PLAN.md) and [backlog](docs/BACKLOG.md).
2. Copy [the blank operator template](assets/PROFILE.md) into a **private Git-ignored** file and add the seller's location, budget, time and intended customers only there.
3. Choose whether to test an owned digital product or creator collaboration with [business-path-selector](skills/business-path-selector/SKILL.md).
4. Find independent commercial evidence, build a minimal working prototype and design a price-based demand experiment before spending or launching.
5. Open [the dashboard](assets/business-studio-offline.html) locally.
6. Run `python3 scripts/validate_repo.py` and `python3 scripts/extract_dashboard_js.py | node --check`.

The example freelance price/quote/profit toolkit and educational creator partnership are **unvalidated hypotheses**. No purchase commitments, sales, rights grants, or audience relationships have been confirmed.
